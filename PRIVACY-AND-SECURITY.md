# Privacy & Security

This repository is public. Before adding material, remove or generalize:

- Passwords, API keys, access tokens, cookies, recovery codes, and secret values.
- Private email addresses, phone numbers, home addresses, precise location, and personal account identifiers.
- Sensitive health, financial, legal, family, or identity information.
- Confidential business information and third-party private content.
- Security weaknesses that could enable abuse before they are responsibly addressed.

## Publishing rule

Only publish information that is appropriate for a public audience and supported by available evidence. A user's broad consent to share project learning does not make credentials, sensitive personal data, or another person's private information safe to publish.

## Corrections

If a privacy or security issue is discovered, stop further distribution and ask the repository owner to remove or remediate the exposed material. Preserve an appropriate non-sensitive correction note where possible.
